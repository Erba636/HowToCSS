Stylování pomocí CSS

Co je to CSS?

CSS (Cascading Style Sheets) je stylovací jazyk, který slouží k určování vzhledu webových stránek. Pomocí CSS se nastavuje, jak mají HTML prvky vypadat – například barvy, písma, velikosti textu, rozložení prvků nebo pozadí. Zatímco HTML popisuje strukturu stránky, CSS se stará o její vizuální podobu.

K čemu se využívá?

CSS se používá k vytváření přehledných, jednotných a moderních webových stránek. Umožňuje měnit vzhled celého webu z jednoho souboru, vytvářet responzivní design pro počítače, tablety i mobilní telefony, přidávat animace, přechody a efekty při interakci uživatele se stránkou. Díky CSS lze oddělit obsah od vzhledu, což usnadňuje údržbu webu.

Způsoby propojení

CSS lze s HTML propojit třemi způsoby. Nejčastější je externí stylopis, kdy je CSS uložené v samostatném souboru a připojené pomocí tagu link . Další možností je interní stylopis, který se zapisuje do značky style v hlavičce dokumentu. Posledním způsobem je inline stylování, kdy se CSS zapisuje přímo do atributu style u konkrétního HTML prvku, což se hodí jen pro drobné úpravy.

Syntaxe

CSS používá jednoduchou a přehlednou syntaxi, která je založena na pravidlech. Každé CSS pravidlo říká prohlížeči, který HTML prvek má být upraven a jak má vypadat. Pravidlo se skládá ze selektoru a deklaračního bloku. Selektor určuje cílový prvek a deklarační blok obsahuje jednotlivé deklarace uzavřené do složených závorek. Každá deklarace se skládá z vlastnosti a hodnoty, které jsou odděleny dvojtečkou. Deklarace se zapisují pod sebe a každá musí končit středníkem. Díky tomu je kód čitelný a snadno upravitelný. CSS je citlivé na správnou syntaxi – chybějící středník nebo závorka může způsobit, že se styl nepoužije.


p {
color: black;
font-size: 16px;
line-height: 1.5;
}

Selektory jsou jednou z nejdůležitějších částí CSS syntaxe. Určují, na které HTML prvky se styl vztahuje. Existuje několik typů selektorů, které umožňují velmi přesné cílení stylů. Základní selektory cílí na značky HTML, pokročilejší pak na třídy, identifikátory nebo kombinace prvků. Třídy se používají tehdy, když chceme stejný styl aplikovat na více prvků. Identifikátory se používají pro jedinečné prvky na stránce. Správné používání selektorů zajišťuje přehledný kód a zabraňuje zbytečnému opakování stylů.


h1 {
color: blue;
}
.text {
font-size: 18px;
}
#hlavni-nadpis {
text-align: center;
}

Vlastnosti a hodnoty určují samotný vzhled prvků. Vlastnost popisuje, co se mění, a hodnota určuje, jakým způsobem. CSS nabízí stovky vlastností, které ovlivňují barvy, písmo, rozměry, okraje, pozicování nebo animace. Hodnoty mohou být různého typu – barvy, délky, procenta nebo klíčová slova. Často se používají jednotky jako pixely (px), procenta (%) nebo relativní jednotky (em, rem). Správná kombinace vlastností a hodnot umožňuje vytvořit responzivní a moderní vzhled webu.


div {
background-color: lightgray;
width: 300px;
padding: 20px;
border: 2px solid black;
}

Jedním ze základních principů CSS je kaskáda. To znamená, že na jeden HTML prvek může působit více stylů současně. Prohlížeč pak rozhoduje, který styl se použije, podle priority. Priorita je ovlivněna typem selektoru, jeho konkrétností a pořadím v kódu. Některé vlastnosti se dědí automaticky z rodičovského prvku na potomky, například barva textu nebo typ písma. Jiné vlastnosti, jako okraje nebo pozadí, se nedědí. Díky pochopení kaskády a dědičnosti lze psát efektivní CSS bez zbytečných opakování.


body {
font-family: Arial, sans-serif;
color: black;
}
p {
color: green;
}
#vyznamny {
color: red;
}

Box model

Box model popisuje, jak je každý HTML prvek na stránce zobrazen a kolik prostoru zabírá. Každý prvek se chová jako obdélník, který se skládá z obsahu (content), vnitřního odsazení (padding), okraje (border) a vnějšího odsazení (margin). Velikost prvku není tvořena jen obsahem, ale také paddingem a okrajem. To může ovlivnit rozložení stránky. Pomocí vlastnosti box-sizing lze určit, zda se do celkové velikosti započítává pouze obsah, nebo i padding a border. Správné pochopení box modelu je základ pro tvorbu přehledného a responzivního webu.

Margin:

20 px

Padding:

20 px

Border:

4 px

Content:

200 px

Ukázka stylování

Časté chyby

Nesprávné používání position

Vlastnosti relative, absolute, fixed a sticky jsou často používány bez pochopení jejich vztahů. Například position: absolute se neřídí vždy celou stránkou, ale nejbližším rodičem s nastavenou pozicí. To může vést k „rozsypanému“ layoutu při změně velikosti obrazovky.

Neresponzivní návrh rozložení

Používání pevných jednotek (např. px) pro šířky a výšky bez ohledu na různé velikosti obrazovek způsobuje problémy na mobilech a tabletech. Stránka pak vyžaduje horizontální posouvání nebo se prvky překrývají. Chybí zde práce s flexibilními jednotkami, media queries nebo moderními layouty jako Flexbox a Grid.

Příliš složité a dlouhé selektory

Snažit se cílit prvky pomocí velmi dlouhých řetězců selektorů zvyšuje specifitu a zhoršuje čitelnost kódu. Takové CSS je pak obtížné udržovat a snadno se rozbije při změně HTML struktury. Lepší je používat jasné třídy a jednodušší selektory.

Ignorování dědičnosti a jejího řízení

Některé vlastnosti se v CSS dědí automaticky, jiné ne. Pokud vývojář nepočítá s dědičností, může docházet k nečekanému chování textu, barev nebo fontů. Často se pak styly zbytečně opakují místo správného využití dědičných vlastností.

Špatná organizace a struktura CSS kódu

Bez jasné struktury, komentářů nebo rozdělení do logických částí se CSS rychle stane nepřehledným. To ztěžuje ladění chyb i týmovou spolupráci. Problémem bývá i absence metodik jako BEM nebo alespoň základních konvencí pojmenování.

Historie CSS

Historie CSS (Cascading Style Sheets) úzce souvisí s vývojem webu jako takového. V počátcích World Wide Webu na začátku 90. let byly webové stránky velmi jednoduché a sloužily především k zobrazování textových informací. Vzhled stránky byl pevně svázán s HTML kódem, který určoval nejen strukturu dokumentu, ale i jeho prezentaci. Používaly se prvky jako font, center nebo atributy pro barvu pozadí a velikost písma, což vedlo k nepřehlednému kódu a obtížné údržbě webů.

Myšlenka oddělit obsah od vzhledu se začala objevovat již v roce 1994, kdy Håkon Wium Lie navrhl koncept kaskádových stylů. Cílem bylo umožnit autorům webových stránek definovat vzhled dokumentu v samostatném stylovém souboru, který by mohl být znovu použit napříč více stránkami. Tento přístup měl výrazně zjednodušit správu webů a zároveň dát větší kontrolu nad jejich vizuální podobou.

První oficiální specifikace CSS, dnes označovaná jako CSS1, byla schválena konsorciem W3C v roce 1996. CSS1 přineslo základní možnosti formátování textu, práci s barvami, okraji, zarovnáním a jednoduchým rozložením stránky. Podpora v tehdejších prohlížečích však byla nejednotná a vývojáři se často potýkali s rozdílným chováním stylů v různých prostředích.

V roce 1998 následovalo CSS2, které rozšířilo možnosti stylování o pokročilejší práci s rozložením, absolutní a relativní pozicování, z-index, media types nebo podporu pro tisk. Přestože CSS2 znamenalo výrazný krok vpřed, jeho implementace byla složitá a mnoho částí nebylo v prohlížečích plně podporováno. To vedlo k frustraci vývojářů a k častému používání různých obcházení a neoficiálních řešení.

Z těchto důvodů vznikla později specifikace CSS2.1, která se zaměřila na stabilizaci a sjednocení chování již existujících vlastností. CSS2.1 se stalo dlouhou dobu praktickým základem webového stylování a výrazně přispělo ke zlepšení kompatibility mezi prohlížeči. Teprve v tomto období se CSS začalo masově prosazovat jako standardní nástroj pro tvorbu moderních webových stránek.

S nástupem CSS3 došlo k zásadní změně filozofie vývoje. CSS již nebylo vydáváno jako jeden celek, ale rozdělilo se na samostatné moduly, které se mohly vyvíjet nezávisle na sobě. Díky tomu bylo možné rychleji zavádět nové funkce, jako jsou zaoblené rohy, stíny, přechody, animace nebo transformace, aniž by bylo nutné čekat na kompletní novou verzi specifikace.

CSS3 také výrazně přispělo k rozvoji responzivního webdesignu. Media queries umožnily přizpůsobovat vzhled stránky různým velikostem obrazovek, což se stalo klíčovým s rozšířením chytrých telefonů a tabletů. Moderní layoutové systémy, jako Flexbox a CSS Grid, pak zásadně změnily způsob, jakým se navrhují rozložení webových stránek, a nahradily starší techniky založené na tabulkách nebo plovoucích prvcích.

V současnosti je CSS nedílnou součástí webového vývoje a neustále se vyvíjí. Přibývají nové vlastnosti, jako jsou proměnné, kontejnery, pokročilé selektory nebo lepší podpora přístupnosti. Historie CSS tak ukazuje dlouhou cestu od jednoduchého formátování textu až k plnohodnotnému nástroji, který umožňuje vytvářet komplexní, moderní a responzivní webové aplikace.
